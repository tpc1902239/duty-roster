# 資料庫後台（Google Apps Script）

放在**勤務表專用的系統 Google 帳號**（密碼只有管理者知道），綁定「勤務表資料庫」試算表。負責讀寫資料、讀分隊 Google 日曆（分隊帳號以唯讀方式分享給系統帳號）。

## 試算表分頁
表格長得跟 4.2 版一樣，可以直接貼、直接改，程式配合表格。

| 分頁 | 樣子 | 用途 |
|---|---|---|
| 人員 | 姓名、番號、別名、身分、勤務方式、狀態、備註 | 取代番名。姓名就是代號；調離的人狀態改「調離」，不刪除 |
| 勤務類別 | 名稱、Z碼、AA碼、AB碼、需輸入、計入服勤時數、計入連續服勤 | 表單 4 的勤務項目 |
| 設定 | 項目、值、說明 | 規則裡的數字，例如備勤最低人數 |
| `YYYY-MM 月班表` | 同 4.2 版月班表：第 1 列番號、第 2 列姓名、A 欄日、B 欄星期、C 欄起代號 | 每月一頁，假表直接貼上，A／B／宿陸續填 |
| `YYYY-MM 存檔` | 同 4.2 版存檔區 | 每月一頁，每天一塊 |
| `YYYY-MM 車輛` | 同 4.2 版車輛：A 單位、B 車種、C 車號、D 欄起 1～31 日的代碼 | 每月一頁 |
| `YYYY-MM 救護訓練` | 日期、時間、訓練項目、訓練地點、教官番號 | 每月一頁；時間以「時間」欄為準 |

- **不在隊**：月班表上把那幾天的格子塗**黑色**（同現在的假表），程式就當作不在隊。
- **番號**：以當月月班表第 1 列為準，程式用姓名認人，月中換番號直接改即可。
- 沒有番號的欄（例如「可填假人數」）、沒有星期的列（例如 11/31）會自動略過。

匯入檔由 `tools/mkdb.py` 從 4.2 版 xlsm 產生（含姓名，**不要放進 repository**）。

## 日曆標題格式
`事項（起-迄）-人名、人名`，例如 `婦宣定期訓練（18-22）-小明`、`休息（18-20）-小華`。
- 沒有人名：待排勤務。沒有時間或整天活動：當作備註。
- 人名對照「人員」分頁的姓名或別名（別名可用頓號分隔多個）。

## 安裝
1. **分隊帳號**：Google 日曆 → 放勤務的日曆「設定和共用」→「與特定使用者共用」加入系統帳號，權限選「查看所有活動詳細資料」；同一頁下方「整合日曆」複製**日曆 ID**。
2. **系統帳號**：把匯入檔上傳到雲端硬碟，開啟後選「檔案 → 儲存為 Google 試算表」。
3. 在試算表選「擴充功能 → Apps Script」，貼上 `Code.gs`、`Auth.gs`（新增指令碼檔，命名 `Auth`）、`Index.html`（新增 HTML 檔，命名 `Index`），`CALENDAR_ID` 填上第 1 步的日曆 ID。
4. 「部署 → 新增部署作業 → 網頁應用程式」，執行身分選「我」，存取權選「任何人」，按部署並授權。資料由網頁的帳號密碼保護，同仁不需要 Google 帳號。
5. 打開部署網址，第一次會請你建立管理員帳號；登入後在「讀取測試」選日期按「讀取」。

## 網頁程式
`Index.html` 只是外殼，每次打開都從 GitHub Pages 載入 `docs/app/app.js`、`app.css` 的最新版，所以改功能只要在 GitHub 合併，不用重新部署 Apps Script。只有 `.gs` 檔改了才需要重貼、重新部署。

## 帳號與紀錄
- 「帳號」分頁：帳號、姓名、角色、鹽、雜湊、啟用。密碼只存雜湊。角色：排班、假表承辦、車輛承辦、救護訓練承辦、管理員。
- 「操作紀錄」分頁：登入、帳號變更等動作都會記下時間和帳號。
