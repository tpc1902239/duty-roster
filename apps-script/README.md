# 資料庫後台（Google Apps Script）

放在分隊 Google 帳號，綁定「勤務表資料庫」試算表。負責讀寫資料、讀 Google 日曆。

## 試算表分頁
| 分頁 | 欄位 | 說明 |
|---|---|---|
| 人員 | 人員ID、姓名、別名、身分、計入人力、勤務方式、備註 | 一人一列，不刪除 |
| 番號期間 | 人員ID、番號、起日、迄日 | 換番號就新增一筆，迄日空白代表到現在 |
| 異動紀錄 | 人員ID、起日、迄日、狀態、備註 | 服兵役、長期訓練、借調等不在隊期間 |
| 月班表 | 日期、人員ID、代號 | 一人一天一列；代號空白代表正常上班 |
| 勤務類別 | 名稱、Z碼、AA碼、AB碼、需輸入、計入服勤時數 | 對應原本表單 4 的勤務項目 |
| 設定 | 項目、值、說明 | 規則參數，例如備勤最低人數 |
| 每日勤務 | 日期、列、勤務名稱、時、人員ID、旗標 | 取代原本的存檔區 |

匯入檔由 `tools/mkdb.py` 從 4.2 版 xlsm 產生（含姓名，**不要放進 repository**）。

## 日曆標題格式
`事項（起-迄）-人名、人名`，例如 `婦宣定期訓練（18-22）-小明`、`休息（18-20）-小華`。
- 沒有人名：待排勤務。沒有時間或整天活動：當作備註。
- 人名對照「人員」分頁的姓名或別名（別名可用頓號分隔多個）。

## 安裝
1. 用分隊帳號把匯入檔上傳到雲端硬碟，開啟後選「檔案 → 儲存為 Google 試算表」。
2. 在試算表選「擴充功能 → Apps Script」，把 `Code.gs` 和 `Index.html` 的內容貼上（新增 HTML 檔時命名為 `Index`）。
3. 如果勤務不在預設日曆，把 `CALENDAR_NAME` 改成日曆名稱。
4. 「部署 → 新增部署作業 → 網頁應用程式」，執行身分選「我」，存取權選「僅限我自己」，按部署並授權。
5. 打開部署網址，選日期按「讀取」。
